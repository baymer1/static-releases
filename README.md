# Static releases

Builds of Static, a watch-together desktop app for Windows.

**New here?** Open the [latest release](https://github.com/baymer1/static-releases/releases/latest), download the `Static-…-windows-x64.zip`, unzip it, and run `Static.exe`.

After that, Static updates itself: it checks this page when it starts, downloads new versions in the background, and shows **Restart to update** when one is ready. Updates install only if they are signed with Static's release key.
